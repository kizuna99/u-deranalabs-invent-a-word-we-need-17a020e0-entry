"Almostalgia" — a word for the lives we nearly lived. English has *nostalgia* for the past that happened; it had no word for the past that almost happened — the city not moved to, the career not taken, the door not opened. **almostalgia** (almost + nostalgia) names that quiet ache in one line. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the coinage and its definition (one line, 82 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
