Nostalgia aches for a past that actually happened, but nothing in English names the ache for the past that nearly did — the move never made, the road not taken, the version of your life that came within reach and then quietly closed. This entry coins **almostalgia** for exactly that feeling and defines it in a single line. Running `node main.ts` checks the line against the contest gate (1–140 characters, not blank) and writes it, with one trailing newline, to `entry.txt` in `/output` (or in `$MAKEFUN_OUTPUT_DIR` when set).
